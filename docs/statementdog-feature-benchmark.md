# 財報狗個股分析與股票健診功能拆解

擷取日期：2026-05-12  
參考標的：群聯電子（8299）

## 1. 為什麼這份拆解重要

財報狗的個股頁已經把資料整理得很完整：財報、獲利、安全性、成長、估值、籌碼、關鍵指標、產品組合都能分頁檢視，也會提供產業排名與代表性公司比較。問題不在於資料不夠，而是使用者仍然需要人工判斷：

- 哪些指標是同方向訊號，哪些是互相矛盾訊號。
- 最新數字是短期雜訊、景氣循環，還是公司體質改變。
- 財報面、消息面、技術面、籌碼面如何合成一份可以行動的研究結論。
- 哪些結論只是儀表板提示，哪些需要回到原始來源、新聞、財報或法說會驗證。

本專案的目標不應只是重做一個財報儀表板，而是把這些分散面向轉成 AI 輔助的完整研究報告：列出證據、矛盾、缺口、追蹤指標與風險邊界。

## 2. 財報狗個股頁的主要功能模組

財報狗個股頁宣稱涵蓋台股與美股 7000+ 家公司，並提供 7 種進出場參考指標、9 種安全性指標、22 種獲利性指標、13 種成長性指標。個股頁的主模組如下。

| 模組 | 頁面 / 功能 | 對 AI 報告的意義 |
|---|---|---|
| 最新動態 | 公司追蹤、投資亮點、投資風險 | 應轉成「最近發生什麼、和投資 thesis 有什麼關係」 |
| 財務報表 | 每月營收、每股盈餘、每股淨值、損益表、總資產、負債和股東權益、現金流量表、股利政策、電子書 | 基本面資料底座；AI 應抽出趨勢、異常與來源 |
| 獲利能力 | 利潤比率、營業費用率拆解、業外佔稅前淨利比例、ROE / ROA、杜邦分析、經營週轉能力、營運週轉天數、合約負債佔營收比例、現金股利發放率 | 判斷產品競爭力、營運效率、盈餘品質 |
| 安全性分析 | 財務結構比率、流動 / 速動比率、利息保障倍數、現金流量分析、營業現金流對淨利比、盈餘再投資比率 | 判斷財務風險、現金流品質、資產負債表壓力 |
| 成長力分析 | 月營收成長率、營收成長率、毛利成長率、營業利益成長率、稅後淨利成長率、每股盈餘成長率、合約負債成長率 | 判斷成長是否持續，以及營收成長有沒有流到獲利 |
| 價值評估 | 本益比評價、本益比河流圖、股價淨值比評價、股價淨值比河流圖、現金股利殖利率、平均現金股息殖利率、平均現金股息河流圖 | 判斷價格相對於獲利、淨值與股息是否偏貴或偏便宜 |
| 董監與籌碼 | 分點籌碼動向、董監持股比例、董監持股質押比例 | 判斷主力、分點、內部人與經營層持股訊號 |
| 關鍵指標 | 長短期月營收年增率、長短期月營收平均值、自由現金流報酬率、Piotroski F 分數、長短期金融借款、現金週轉循環、彼得林區評價、股利折現評價、現金流折現評價、大股東持股比率 | 將財報與估值濃縮為可比較的高階因子 |
| 產品組合 | 產品組合營收、產品組合營收成長率、銷貨地區、供應商、客戶；部分頁面也顯示產品銷售額、銷售量、單價、產能與產量、產能利用率、區域銷售額 | 判斷成長來源、產品結構、客戶 / 供應商集中度 |

## 3. 個股頁單一指標頁的共同設計

從使用者提供的頁面看，單一指標頁大致有這些功能：

| 功能 | 說明 | 例子 |
|---|---|---|
| 最新數字摘要 | 用一句話說明最新值、創高 / 創低、連續成長或下降、和同業或市場百分位比較 | 月營收頁顯示最新營收、月增、年增、連續成長月數 |
| 指標定義 | 解釋該指標在衡量什麼 | 本益比頁說明本益比是股價相對 EPS 的高低 |
| 解讀建議 | 提醒該指標如何搭配其他指標看 | 月營收頁提醒不能只看單月數字，需搭配營收成長率 |
| 近期歷史表 | 顯示最近數月或數季資料 | 月營收顯示 202601 到 202604；利潤比率顯示 2025Q2 到 2026Q1 |
| 長期歷史資料 | 提供 20 年歷史數據，但部分需要登入或付費 | 多個頁面顯示「請先登入為會員，查看 20 年歷史數據」 |
| 相關產業排名 | 依該指標列出公司在多個相關族群中的排名 | 群聯在 SSD、NAND Flash、記憶體控制 IC 等族群中的排名 |
| 代表性公司比較 | 與各族群營收前三大的代表性公司比較 | 月營收、毛利率、負債比、本益比頁都有代表性公司比較 |
| 相關產業排行榜 | 顯示同族群中該指標排名前段公司 | 方便找同業 benchmark，但仍需人工解讀差異 |
| 付費解鎖 | 進階資料、完整歷史或完整健診細節可能需要登入 / 付費 | 股票健診、分點籌碼與長期資料多有鎖定 |

## 5. 股票健診的 7 種分析角度與完整指標

### 5.1 排除地雷股健診

目的：先排除財務風險高、可能有倒閉或體質惡化疑慮的公司。分數越高，代表地雷股風險越小。

使用 6 個指標：

1. 自由現金流入近五年是否有三年大於 0。
2. 自由現金流入近五年是否平均大於 0。
3. 營業現金流入對淨利比近五年是否有三年大於 100%。
4. 營業現金流入對淨利比近五年是否平均大於 100%。
5. 應收帳款週轉天數是否小於等於去年同期數據。
6. 存貨週轉天數是否小於等於去年同期數據。

AI 報告應補強：這組指標只告訴你風險是否偏高，還要追問「為什麼現金流好 / 壞」、「應收或存貨變化是否和產業循環、產品組合或一次性因素有關」。

### 5.2 定存股健診

目的：判斷公司是否適合作為高股息、穩定配息型標的。

使用 5 個指標：

1. 近一年股息殖利率是否大於 6%。
2. 近五年平均股息殖利率是否大於 6%。
3. 連續五年是否都有發股息。
4. 股息發放率五年內是否有三年大於 50%。
5. 股息發放率是否五年平均大於 50%。

AI 報告應補強：高殖利率可能來自股價下跌，不一定代表便宜；需要檢查自由現金流、盈餘穩定度、產業景氣與未來配息可持續性。

### 5.3 成長股健診

目的：判斷公司短期業績是否具備爆發力。

使用 5 個指標：

1. 月營收 YoY 連續三個月大於 0。
2. 近一季毛利年增率大於 0。
3. 近一季營業利益年增率大於 0。
4. 近一季稅前淨利年增率大於 0。
5. 近一季稅後淨利年增率大於 0。

AI 報告應補強：成長股檢核要把「營收成長」一路追到「毛利、營業利益、稅後淨利」，並判斷成長是價格、出貨量、產品組合、匯率或一次性因素造成。

### 5.4 便宜股健診

目的：判斷股價相對於業績與資產是否可能被低估。

使用 6 個指標：

1. 本益比是否在 5 年內區間最低 20%。
2. 本益比是否低於 50% 公司。
3. 股價淨值比是否在 5 年內區間最低 20%。
4. 股價淨值比是否低於 50% 公司。
5. 近一年股息殖利率是否大於 6%。
6. 近五年平均股息殖利率是否大於 6%。

AI 報告應補強：低 P/E 或低 P/B 可能是價值低估，也可能是景氣循環下行、獲利高點、資產品質惡化或市場不相信未來 EPS。AI 應輸出「便宜的可能原因」與「價值陷阱風險」。

### 5.5 籌碼健診

目的：判斷內部人、投資法人、大股東等資金是否偏向累積或退出。此功能是付費進階功能，且目前只適用台股公司。

使用 3 個指標：

1. 持股超過 5000 張的大股東持股比重是否連續三個月上升。
2. 董監持股最新數值是否較 12 個月前持平或上升。
3. 總股東人數是否連續三個月下滑。

AI 報告應補強：籌碼只能提供行為訊號，不能自動等同基本面改善。應和消息面、股價位置、成交量、法說會、董監質押與分點資料一起看。

### 5.6 績優股健診

目的：判斷公司是否獲利優秀、體質穩健且股價合理。此功能是付費進階功能，且目前只適用台股公司。

使用 5 個指標：

1. 公司上市是否超過三年。
2. 公司自由現金流報酬率和去年相比是否沒有下滑。
3. 公司 3 年平均自由現金流報酬率排名是否在最高的前 20%。
4. 公司過去 3 年營業利益加總是否大於 0。
5. 股價淨值比 + 本益比 + 殖利率綜合排名是否在前 50 名。

AI 報告應補強：績優股不是只看穩健，還要判斷護城河、產品競爭力、景氣循環位置、管理層資本配置與估值是否已反映品質。

### 5.7 轉機股健診

目的：判斷股價與業績低迷的公司是否可能出現反轉。此功能是付費進階功能，且目前只適用台股公司。

使用 3 個指標：

1. 公司股價淨值比是否小於 3 倍。
2. 公司的 F-score 是否在 8 分以上。
3. 公司股價淨值比是否為台股中最低的前 50 名。

AI 報告應補強：轉機股需要特別小心「低估值」和「基本面惡化」混在一起。AI 應要求具體轉機證據，例如訂單、產品、毛利率、資產處分、債務改善、產業循環反轉，而不是只因低 P/B 就判斷反轉。

## 6. 對本專案的產品要求

### 6.1 AI 不是儀表板，而是投資研究統整層

財報狗頁面最大的價值是指標整理與比較，但它的操作模式仍然是「人打開很多頁，自己組合結論」。本專案應改成：

1. 系統讀取並整理消息面、基本面、技術面、籌碼面、估值面。
2. 各代理分別產生可追溯觀點。
3. AI 把觀點合成一份完整報告，而不是只把指標列出來。
4. 報告必須標示矛盾與缺口，例如「營收強，但估值也高」、「籌碼轉強，但基本面尚未確認」、「毛利率創高，但可能受循環或產品組合影響」。
5. 使用者看到的應是結論、證據、反方觀點、追蹤指標與資料缺口，不是被丟回儀表板自己分析。

### 6.2 建議的 agent 分工

| Agent | 負責內容 | 對應財報狗 benchmark |
|---|---|---|
| Health Check Agent | 將 7 種健診轉成 pass / fail / unknown / not applicable，並說明原因 | 股票健診 |
| Fundamental Agent | 營收、毛利率、營業利益、淨利、ROE / ROA、現金流、週轉天數 | 財務報表、獲利能力、安全性、成長力 |
| Valuation Agent | P/E、P/B、殖利率、DCF / DDM / Peter Lynch valuation、歷史區間與同業比較 | 價值評估、關鍵指標 |
| Chip Agent | 分點籌碼、董監持股、董監質押、大股東持股比率、股東人數 | 董監與籌碼、籌碼健診 |
| Technical Agent | 價格趨勢、成交量、動能、均線、波動與支撐壓力 | 財報狗較少直接覆蓋，需補外部技術面資料 |
| News / Catalyst Agent | 最新新聞、法說、產業消息、政策、券商摘要 | 補足儀表板未整理成 thesis 的消息面 |
| Synthesis Agent | 將各 agent 結論合成詳盡報告 | 本專案核心差異化 |
| Evaluation Agent | 檢查來源、矛盾、過度推論、資料缺口與是否越界成買賣建議 | 本專案 guardrail |

### 6.3 報告最低應包含

1. 一句話結論：偏多 / 偏中性 / 偏空，但不得變成買賣指令。
2. 核心 thesis：為什麼這家公司值得研究。
3. 最新變化：營收、獲利、估值、籌碼、消息面最近有什麼變化。
4. 股票健診摘要：7 種健診 pass / fail / unknown / not applicable。
5. 基本面拆解：營收、毛利率、費用率、淨利、EPS、現金流、負債、週轉。
6. 成長品質：營收成長是否真的轉成獲利成長。
7. 估值情境：P/E、P/B、殖利率、情境 EPS 與敏感度。
8. 技術與籌碼：價格位置、量能、分點、董監、大股東。
9. 反方觀點：哪些因素會推翻原 thesis。
10. 資料缺口：哪些資料尚未取得，哪些頁面或來源是登入 / 付費限制。
11. 追蹤指標：下一次更新時要看哪些數字。
12. 來源與信心：每個重要結論附來源、日期與信心等級。
